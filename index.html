使用说明

开始使用：将此 HTML 文件保存在固定文件夹，使用 Windows 上的 Edge 或 Chrome 打开。无需安装 Python，无需网络。

四个属性：重要性为 −10～10 的数值；截止时间直接决定地图纵轴位置；困难度为 1–10 级；工作量使用数值表示，支持小数。

Markdown：在纯文本编辑框输入内容，点击“Markdown 预览”查看排版，随时切回编辑。保存时保留显示模式，点击地图上的标题标签可阅读全文。支持常用 Markdown（标题、列表、任务清单、引用、代码、表格、链接）。原始 HTML 仅作为文字显示；远程图片只显示说明与链接。

地图：仅提供重要性 × 截止日期视图，越早截止的任务越靠上；纵轴刻度最小间隔为 1 天。圆圈半径按当前视图内工作量平方根归一化为 10～42；只有一个日程或工作量相同时半径为 24。拖动边缘时暂时固定显示比例，松开后重新归一化；重要性 0 与今天将背景划分为四个区域，圆圈颜色表示困难度。电脑端左键拖动空白区域进行框选，框中的多个圆可同时选中；拖动任一已选圆内部可整体平移选中圆，其中纵向移动按整天调整截止日期；按住圆圈边界并上下移动鼠标调整半径，松开后确认并退出，多选时所有已选圆同步缩放；按住 Ctrl 时光标变为抓取手势，左键拖动可平移整个视图。滚轮默认上下移动视图，Shift + 滚轮左右移动，Ctrl + 滚轮以鼠标位置为中心缩放。右键地图（手机长按）按所在重要性和日期创建日程。

日程连接：单选日程后右键（手机长按）选择“连接”，再点击另一个圆圈或标签；黑色实线表示两个日程的连接。连线跟随圆圈位置和大小更新，两端都在视图内时显示。虚线为待完成的连接，可按 Esc 或“取消连接”退出。连接自动保存在本地，并包含在版本 6 的备份中；旧版本软件不支持该备份格式。

本地保存：每次修改自动保存到当前浏览器的 localStorage。请固定使用同一浏览器、同一文件位置，并避免无痕模式。清除浏览器数据、移动或重命名文件后，数据可能无法继续读取。

备份迁移：点击“导出备份”下载 JSON 文件。导入采用合并方式；相同 ID 的日程以备份内容更新，其余保留。删除前会确认，删除后短时间内可撤销。支持导入旧版备份；旧版中的迫切性字段会被忽略，重要性和截止时间继续保留；版本 1 日程困难度默认为 5，细节默认为纯文本。

数据不发送到服务器。本软件没有后台通知功能，关闭页面后不会弹出提醒。
