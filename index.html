使用说明

开始使用：将此 HTML 文件保存在固定文件夹，使用 Windows 上的 Edge 或 Chrome 打开。无需安装 Python，无需网络。

四个属性：重要性与迫切性均为独立的正负小数，不与截止时间绑定；困难度为 1–10 级；截止倒计时独立刷新；任务量以预计小时数记录，支持小数。

Markdown：在纯文本编辑框输入内容，点击“Markdown 预览”查看排版，随时切回编辑。保存时保留显示模式，点击地图上的标题标签可阅读全文。支持常用 Markdown（标题、列表、任务清单、引用、代码、表格、链接）。原始 HTML 仅作为文字显示；远程图片只显示说明与链接。

地图：仅提供重要性 × 迫切性视图。圆圈大小按固定坐标比例表示任务量，不随可见任务变化；圆半径与地图坐标使用同一缩放尺度，因此缩放地图时圆圈会同步缩放，并保留坐标尺度下的最小半径；x=0 与 y=0 将背景划分为四个不同颜色的象限；圆圈颜色表示困难度。电脑端左键拖动空白区域进行框选，框中的多个圆可同时选中；拖动任一已选圆内部可整体平移选中圆，按住圆圈边界并上下移动鼠标调整半径，松开后确认并退出；多选时所有已选圆同步缩放；按住 Ctrl 时光标变为抓取手势，左键拖动可平移整个视图。滚轮默认上下移动视图，Shift + 滚轮左右移动，Ctrl + 滚轮以鼠标位置为中心缩放。右键地图（手机长按）创建日程；手机端仍使用单指拖动与双指缩放。“适配全部筛选任务”查看范围外任务。

本地保存：每次修改自动保存到当前浏览器的 localStorage。请固定使用同一浏览器、同一文件位置，并避免无痕模式。清除浏览器数据、移动或重命名文件后，数据可能无法继续读取。

备份迁移：点击“导出备份”下载 JSON 文件。导入采用合并方式；相同 ID 的日程以备份内容更新，其余保留。删除前会确认，删除后短时间内可撤销。支持导入旧版备份，旧日程迫切性初始化为 0，重要性和截止时间保留；版本 1 日程困难度默认为 5，细节默认为纯文本。

数据不发送到服务器。本软件没有后台通知功能，关闭页面后不会弹出提醒。
