使用说明

开始使用：将此 HTML 文件保存在固定文件夹，使用 Windows 上的 Edge 或 Chrome 打开。无需安装 Python，无需网络。

四个属性：重要性与困难度均为 1–10 级；迫切性由截止时间自动计算，每秒刷新倒计时；任务量以预计小时数记录，支持小数。

Markdown：在纯文本编辑框输入内容，点击“Markdown 预览”查看排版，随时切回编辑。保存时保留显示模式，清单中展开细节可阅读全文。支持常用 Markdown（标题、列表、任务清单、引用、代码、表格、链接）。原始 HTML 仅作为文字显示；远程图片只显示说明与链接。

图表一：横轴重要性，纵轴迫切性（越靠上越迫切），圆面积与任务量成正比。

图表二：横轴迫切性（越靠右越迫切），纵轴任务量（小时），圆面积与重要性成正比。迫切性使用剩余时间的非线性刻度，逾期区域单独标出。两个图表均用颜色表示困难度，1 级绿色渐变至 10 级红色；悬停可查看精确数值，点击可编辑，右键圆点可直接删除；键盘聚焦圆点后也可按 Delete 删除。重叠的小圆可从清单访问。

本地保存：每次修改自动保存到当前浏览器的 localStorage。请固定使用同一浏览器、同一文件位置，并避免无痕模式。清除浏览器数据、移动或重命名文件后，数据可能无法继续读取。

备份迁移：点击“导出备份”下载 JSON 文件。导入采用合并方式；相同 ID 的日程以备份内容更新，其余保留。删除前会确认，删除后短时间内可撤销。支持导入旧版备份，旧日程困难度默认为 5，细节默认为纯文本。

数据不发送到服务器。本软件没有后台通知功能，关闭页面后不会弹出提醒。
